Yeh project ek simple aur fast web-based attendance system hai. Isse ek teacher ki madad ke liye banaya gaya hai jinki official ERP ID abhi tak nahi bani hai. Manual attendance lene mein jo time waste ho raha tha, is tool ne usse ek click ka kaam bana diya hai. ❤️

## ✨ Features (Isme kya kya hai?)

- 🕒 **Live Clock & Date:** Upar current date aur time hamesha update rehta hai.
- 🖱️ **One-Click Toggle:** Student ke card par click karein -> **Green Tick (Present)**. Dobara click karein -> **Red Mark (Absent)**. (Koi cross ka nishaan nahi, ekdum clean look).
- 🔄 **Daily Auto-Reset:** Har naye din par system apne aap fresh ho jata hai. Kisi purane data ko manually delete karne ki zaroorat nahi.
- 📲 **WhatsApp Integration:** "Send to Absentees" button dabaate hi saare absent baccho ki list copy ho jati hai, jise aap seedha WhatsApp par parents ko bhej sakte hain.
- 🔢 **Auto Numbering:** Har student ke naam ke aage serial number (1, 2, 3...) automatic aa jata hai.
- 💾 **Local Storage:** Data aapke browser mein safely save hota hai. Page band karne par bhi data nahi udta.

---

## 🚀 How to Use (Kaise chalayein?)

Kisi bhi installation ki zaroorat nahi hai! Bas link kholiye aur use kariye.

1. **Live Website Kholiye:** Upar diye gaye **Live Demo** button par click karein.
2. **Attendance Mark Karein:** Jo student aaya hai uske card par click karein (Green ho jayega). Jo nahi aaya wo automatically Red (Absent) rahega.
3. **Message Bhejein:** Niche **"Send to Absentees"** par click karein. Ek message format copy ho jayega. Use class group ya parents ko WhatsApp kar dein.
4. **Save Karein:** Upar **"Save Attendance"** button daba kar data save kar sakte hain.
